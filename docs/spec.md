# 仕様（試作）

何がどう動くかの決まり。見た目は `design.md`、コードの置き場所は `architecture.md`。

## 1. 遊びの流れ
読む → 生まれる（変身）→ 棚に並ぶ → 3体えらんでバトル → 挑戦状を友達に送る。
日がたつと「入荷」して、同じ商品から新しいロットに会える。

## 2. 画面
下に3つのタブ（読む・棚・バトル）。URLの `#` 以降で画面が決まり、ブラウザの「戻る」で前の画面に戻る。

| 画面 | URL | 中身 |
|---|---|---|
| 読む | `#/` | スキャナ窓、カメラで読む、写真から読む、数字の入力、架空の試し番号 |
| 棚 | `#/shelf` | 読んだキャラを品番ごとに1体ずつ。ロットの数、入荷までの日数 |
| 値札 | `#/c/品番` `#/c/品番/何体目` | キャラ1体。味・技・能力・バーコード・ロット番号、ロットの切り替え、次の入荷 |
| バトル | `#/battle` | 今日の挑戦者、届いた挑戦状、挑戦状を送る、味の輪 |
| チーム選び | `#/battle/daily` `…/letter` `…/send` | 棚から3体えらぶ（自動の試合では、えらんだ順に前に立つ） |
| 試合（手を出せる） | `#/battle/live` | 今日の挑戦者との試合。ねらう・ふく・技。結果のレシート |
| 試合（自動） | `#/battle/play` | 挑戦状の試合。見るだけ。結果のレシート |

### 読む
- スキャナ窓（押すとカメラが始まる）、「カメラで読む」「写真から読む」
- 手入力（13桁・12桁・8桁。チェック数字で検証）。手入力と試し番号で生んだ子には「手入力」の印が付く（オンライン対戦には出せない予定）
- 架空の試し番号3つ（棚が空のうちは開いて見せる）
- はじめての人には見出しと説明、2回目からは短い見出しだけ

### 値札
- 生まれた直後だけ変身演出（約2.9秒。動きを減らす設定の端末では省略）
  1. 値札ラベルにバーコード、レーザーが2回光る（ピッ）
  2. ラベルがはがれる
  3. 普通の棒24本が体の縞へ、長い棒6本が頭の飾りへ飛ぶ
  4. 体がふくらみ、棒が縞に変わり、顔が出て、跳ねて首をかしげる
- 値札：味、バーコードの種類、名前、色と系統、技、強い味・弱い味、能力5つ（品番からの差と、バトルでの役割）、バーコード、ロット番号
- 生まれた直後の札：はじめての品番です／新しいロットが入荷しました／前と同じロットです
- 同じ品番のロットが2体以上いれば、ロット番号で切り替えられる
- 次の入荷：入荷まであと◯日◯時間／入荷しています
- 「もう1個読む」「画像にする」（1080×1350のPNG。長押しで保存）

### 棚
- 品番ごとに1体（いちばん新しいロットの姿）。最後に読んだ品番が先
- キャラは棚板の上に立ち、下に値札が下がる（名前、味、ロットが2体以上なら「×2」）。入荷していれば赤い丸シールと「入荷あり」、まだなら「入荷まで◯日」
- 7品番以上になると、味でしぼれる

## 3. キャラの決まり方
- 品番から：系統（かわいい／かっこいい）、味6種、色（味ごとに3種）、体形（超楕円）、耳、縞の入り方（お腹のラベル／全身／帯／背中）、目、口、腕、名前、技、能力の基準値
- ロットから：色味のずれ±9°、首のかしげ±6°、キラ目、ほっぺ、シール、能力±8
- 商品の中身（味）が決まれば、味・色・技だけをそれで上書きする。ほかの部位は変わらない

### 中身（味）の決まり方
品番ごとに、はじめて読まれたときに1つだけ決まり、全員に同じものが配られる（サーバーに残す）。読んだ人には聞かない（変身を止めない）。

1. もう決まっていれば、それを使う
2. Open Food Facts に載っていれば、商品名・カテゴリの文字を辞書（キーワード）で「ぶどう」「コーヒー」などに分けて決める。AIは使わない
3. 載っていなければ、メーカー番号（JANの頭の数桁）から推測する。その会社の商品の多くが同じ中身だとデータで確かめられた会社だけ（コーヒーの会社ならコーヒー、など）。推測なので値札には「コーヒーっぽい商品から生まれた」と言い切らずに書く
4. それでも分からなければ「中身なし」で決める。姿・味・技は品番（バーコードの番号）だけで決まる
   - 「中身なし」も答えとして残すので、あとで Open Food Facts に載っても姿は変わらない
   - サーバーに届かないとき（オフラインなど）は品番だけで生まれ、次に読んだときにもう一度聞く

一度決まった中身は端末にも残し、あとから姿が変わらないようにする。

## 4. ロット（消費サイクル）
- 同じ品番を読んでも、前のロットから消費サイクルが過ぎるまでは同じロット
- 消費サイクル：商品3日、お店のラベル（先頭 02・04・20〜29）1日、本・雑誌7日
- ロット番号は `L年月日-何体目`（例 L261115-001）

## 5. バトル
3体対3体（棚が3体より少なければ、いる分だけ）。試合は2種類ある。

| | 手を出せる試合 | 自動の試合 |
|---|---|---|
| 相手 | 今日の挑戦者（日付で決まるCPU。何度でも挑める。その日の結果を覚える） | 挑戦状（友達が送ったURL） |
| 進み方 | リアルタイム。自動で攻撃しあう中で、ねらう相手・拭く味方・技を自分で出す | 始まる前に結果が決まっていて、見るだけ。誰が開いても同じ試合 |
| 計算 | `src/core/live.ts`（調整値は `LIVE`） | `src/core/battle.ts`（調整値は `TUNE`） |

### どちらにも共通
- 能力の役割：内容量＝体力（残り◯ml）、濃さ＝からだ攻撃、香り＝あじ攻撃、キレ＝素早さ、コク＝守り。香りは 2026-11-26 に足した（自動の試合では使わない）
- 味の輪：あまい→からい→うまい→すっぱい→にがい→しょっぱい→あまい（左が右に強い）。有利なら1.5倍、不利なら0.75倍
- 組み合わせ技（晩酌コンボ、おやつタイム、ジャンクの誘惑、まろやか救済、いちごミルク、レモンスカッシュ、おにぎり定食、フルーツポンチ）：入った体の濃さ1.25倍
- 3体とも同じ味なら守り1.2倍
- チーム選びでは、相手の味に対して強い・弱いの印と、組み合わせ技の予告が出る

### 手を出せる試合
- 3体とも、自分の間隔（キレが高いほど短い。3〜4.8秒）がたまると、攻撃の**列**に並ぶ（同時なら、キレの高い順）
- **攻撃は1つずつ**：列の先頭の子が**ため**（0.8秒）→ 当たる → ひと呼吸（0.6秒）→ 次の子。並んでいる間は間隔が進まない。ためている子の頭の上に「！」（相手は赤、こちらは黄色）が出て、ねらわれている味方の足もとに赤い点線の輪が出る
- 先頭はない。どの攻撃も、相手の3体の誰にでも当たる。ねらう相手がいなければ、相性と減り具合を見て（半分は考えずに）選ぶ
- 攻撃は2種類
  - **からだ**（体当たり）：濃さで強くなる
  - **あじ**（味のしぶきが飛ぶ）：香りで強くなる。少し弱いかわりに、当てた相手に**効き目**が付く（8秒。かかり直すと最初から）
- 濃さと香りの片方がもう片方の1.12倍以上なら「からだ型」「あじ型」で、4回に3回は得意なほうを使う。それ以外は「両方」で半々。型は絵の左下に出る
- 効き目は味で決まる

  | 味 | 効き目 | 中身 |
  |---|---|---|
  | あまい | とろける | 攻撃の間隔が1.5倍に延びる |
  | からい | ひりひり | 2秒ごとに、当たったときの35%ずつ減る |
  | すっぱい | きゅっ | 守り（コク）が0.7倍になる |
  | にがい | しぶい | 攻撃（濃さ・香り）が0.72倍になる |
  | しょっぱい | のどがかわく | 技のゲージがたまらない |
  | うまい | （うまみ） | 付く効き目はなく、与えた量の60%ぶん、いちばん減っている味方が回復する |

- 操作は3つ
  - **ねらう**：相手をタップすると、こちらの攻撃（技も）がその子に集まる。もう一度タップでやめる。その子が倒れたら自動でやめる
  - **ふく**：効き目が付いた味方の「ふく」を押すと、その子の効き目が全部取れる。拭いたあと8秒は、チームの誰も拭けない
  - **技**：攻撃したり受けたりするとゲージがたまり、満タンなら押せる（ふつうの攻撃の3倍。からだ型はからだ、あじ型はあじ、両方は強いほうで出る。味の相性も乗る）。押した技は列に割り込み（ほかの技の後ろ）、今の攻撃が終わったら出る。待っている間はボタンに「次に出る」。技のあとのひと呼吸は1秒。満タンのまま6秒放っておくと勝手に列に入る。相手のゲージのたまり具合も見える
- 今日の挑戦者（CPU）は、技を満タンから4〜7秒で出し、効き目が付いた味方を3〜7秒で拭く。ねらいはしない
- 印（強・弱）：こちらの子は「ねらっている相手に強いか弱いか」（ねらっていなければ出ない）。あいての子は「こちらのみんなから見て、強い味が多いか弱い味が多いか」
- 全員倒れたら負け。2分で決着しなければ、残りの量の割合で判定
- 1試合はおよそ1分（倍速なら30秒）。攻撃は1試合に45回ほど（1.4秒に1回）、技は両チーム合わせて6回ほど
- **倍速**：試合の上の「倍速」を押すと、すぐ2倍の速さになる（もう一度押すと戻る。端末に覚える。最初はふつうの速さ）。秒で書いた時間はふつうの速さのもの
- 同じチーム・同じ種・同じ操作の列なら、同じ試合になる
- 手応え：からだは体当たり、あじは体をしぼって味の色の粒を山なりに飛ばす。縞のはじけ・減った量の数字・効き目の札・回復の数字・揺れ（相性がいいときと技は大きく）・技名の値札・開始と勝ち負けの帯・効果音と振動。音は試合の上のボタンで消せる（端末に残る）。動きを減らす設定の端末では、動きは出さない
- 計画との違いと、決めてほしいことは `docs/battle-plan.md`
- **3Dの舞台（お試し・battle-3d ブランチ）**：手を出せる試合は、売り場（床・棚・特売のPOP）を three.js で描き、キャラの絵を白いふちのシールにして立たせる。こちらは手前、相手は奥に、3体ずつ横に並ぶ（真ん中が少し前）。ねらっている相手の足もとに赤い輪。体当たりは途中まで踏み込み、からだの技だけ相手まで跳ぶ。あじは味の色の玉が山なりに飛ぶ。当たった瞬間に少し止まる・カメラが揺れて寄る・縞の破片が飛び散る。こちらの3体は少し小さく、どの画面の縦横比でも左右からはみ出さない。相手のためは頭の上の赤い「！」。倒れた体は後ろに寝て色が抜ける。上下の列は名前・体力・操作だけになる。試合の上の「2Dで見る／3Dで見る」で切り替え（端末に残る。押すと試合は最初から）。残すか決めるまでは、最初は2Dで開く。WebGLが使えない端末では2Dのまま

### 自動の試合
- 行動順はキレ順、攻撃は相手の先頭へ。有利のときは理由を実況
- 12ラウンドで決着しなければ、残りの量の割合で判定
- 「結果まで飛ばす」で一気に結果へ
- 効果音と、相性がいいときの揺れがある

### 挑戦状
- 自分のチーム（品番・ロット・味）を `?vs=` に入れたURL。サーバーなしで、誰が開いても同じ試合になる
- 受け取った人は、棚にキャラがいればそのままチーム選びへ。いなければ、まず1体生んでから「バトル」で受けて立つ
- 届いた挑戦状は、タブを閉じるまで「バトル」に残る（何度でも戦える。「受けない」で消える）

## 6. やらないこと（この段階）
ログイン、ランキング、商品名の表示、刻印ボーナス（賞味期限の読み取り）。
オンライン対戦はまだ無い（進め方は `ideas.md`。手を出せる試合がその土台）
