# 試作の仕様（第1段階）

## 範囲
「スキャン → 縞がはがれて組み上がる → キャラ誕生」の1画面と、ロットの出し方（消費サイクル）だけ。

## 画面
### ホーム
- 見出し、スキャナ窓（カメラ映像＋赤いレーザー線）
- 「カメラで読む」「写真から読む」
- 手入力（13桁・12桁・8桁。チェック数字で検証）
- 架空の試し番号3つ
- 棚：読んだロットの一覧（新しい順、最大40）。押すと値札を再表示

### 誕生
- 変身演出（約2.9秒。動きを減らす設定の端末では省略）
  1. 値札ラベルにバーコード、レーザーが2回光る（ピッ）
  2. ラベルがはがれる
  3. 普通の棒24本が体の縞へ、長い棒6本が頭の飾りへ飛ぶ
  4. 体がふくらみ、棒が縞に変わり、顔が出て、跳ねて首をかしげる
- 値札：味、バーコードの種類、名前、色と系統、技、能力4つ（品番からの差）、バーコード、ロット番号
- 状態表示：はじめての品番／新しいロットが入荷／前と同じロット（次の入荷まで◯日）
- 「もう1個読む」「画像にする」（1080×1350のPNG。長押しで保存）

## キャラの決まり方
- 品番から：系統（かわいい／かっこいい）、味6種、色（味ごとに3種）、体形（超楕円）、耳、縞の入り方（お腹のラベル／全身／帯／背中）、目、口、腕、名前、技、能力の基準値
- ロットから：色味のずれ±9°、首のかしげ±6°、キラ目、ほっぺ、シール、能力±8

## やらないこと（この段階）
商品名の取得、バトル、オンライン、ログイン、刻印ボーナス（賞味期限の読み取り）

# 第2段階：バトル

- 棚から3体えらぶ（えらんだ順に前に立つ）。相手は「今日の挑戦者」（日付で決まるCPU）か「挑戦状」（友達が送ったURL）
- 自動で進む。行動順はキレ順、攻撃は相手の先頭へ。体力は「残り◯ml」
- 味の輪で有利なら1.5倍（理由を実況）、不利なら0.75倍
- 組み合わせ技（晩酌コンボ、おやつタイム、ジャンクの誘惑、まろやか救済、いちごミルク、レモンスカッシュ、おにぎり定食、フルーツポンチ）：入った体の濃さ1.25倍
- 3体とも同じ味なら守り1.2倍
- 12ラウンドで決着しなければ、残りの量の割合で判定
- 「結果まで飛ばす」で一気に結果へ
