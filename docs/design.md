# 見た目と画面設計

## 1. 見た目の方向
舞台はスーパーの売り場。値札、レジのスキャナ、感熱紙のレシート、特売POP。

### 色
| 名前 | 色 | 使いどころ |
|---|---|---|
| 感熱紙 | #F3F5F2 | 背景（少し青みの白。クリーム色にしない） |
| インク | #1D1D22 | 文字、輪郭線、バーコード、相手チームの台 |
| 値札の黄 | #FFD83D | キャラの値札、えらんだ状態、今いるタブ |
| 特売の赤 | #E63B2E | レーザー、新ロットの札、入荷あり、お知らせ、フォーカス枠 |
| レシートの灰 | #B6BCC0 | 区切り線 |

味の札の色（見分けるためだけに使う。キャラの体色とは別）：あまい #F9B5C8、からい #F0685A、うまい #E9C68C、すっぱい #F2EE6B、にがい #9FCB86、しょっぱい #BFE4F2。

色・文字・寸法の値は `src/styles/tokens.css` にまとめてある。色を足すときはここに名前を付けて足す。

### 文字
- 見出しとキャラ名は Dela Gothic One（POPの太さ）
- 本文は Zen Kaku Gothic New
- 数字（JAN、ロット番号、日付、レシートの数字）だけ等幅

### 形
- キャラも部品も「太い黒の輪郭線」（3px）で統一。シール・ステッカーの手触り
- ボタンはレジのキーのように下辺が厚い。押すと沈む
- 部品は、売り場に実際にある物の形から作る（下の「部品」）。どのアプリにもある部品（角丸のカードを積む、丸い札を並べる、アイコン付きのタブ）は使わない
- 角は小さく（6〜8px）。丸くするのは、丸いシールだけ
- 文字は左ぞろえが基本。中央ぞろえは、値札の穴・レシートの見出し・試合の場面だけ
- キャラは値札の上か、棚板（太い線）の上に立つ。値札には吊るし穴、能力はレシートの点線リーダーで並べる

### 動き
- 大きく動くのは変身と、バトルの手応え（体当たり・縞のはじけ・揺れ）だけ。変身のあいだは値札も下のタブも引っ込める
- バトルのはじけ（当たったところで放射状に飛ぶ棒）は、バーコードの縞と攻撃した子の色でできている。ここも「縞」で統一する
- それ以外は、押したときの反応と、バトルの小さな反応（跳ねる・揺れる・数字が浮く）、結果のレシートが出てくる動きだけ
- 動きを減らす設定の端末では、変身は完成形だけ、バトルは結果まで一気に進む

### 似せないもの
モンスター図鑑RPGのUI、ガチャのレア度演出、Material/Tailwindの初期見た目。

## 2. 画面の組み立て
やることは3つ（読む・集める・戦う）で、どれも同じ重さ。だから下に3つ並べ、どこからでも1回で行けるようにする。

```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ 読む   #/      │  │ 棚   #/shelf   │  │ バトル #/battle │
│ スキャナ窓     │  │ 品番ごとに1体  │  │ 今日の挑戦者   │
│ 数字の入力     │  │                │  │ 挑戦状         │
└──────┬───────┘  └──────┬───────┘  │ 味の輪         │
       │ 読めた           │ 押す      └──────┬───────┘
       ▼                  ▼                  ▼
┌─────────────────────────────┐   チーム選び  #/battle/daily ほか
│ 値札  #/c/品番/何体目          │          ▼
│ （読んだ直後だけ変身）         │   試合 → 結果のレシート  #/battle/play
└─────────────────────────────┘
        [ 読む | 棚 | バトル ]   ← 下のタブ（黒い帯）
```

- 下のタブは黒い帯に3語だけ。今いる所が値札の黄になる。「バトル」には、まだ挑んでいない今日の挑戦者か、まだ受けていない挑戦状があると赤い印が付く
- チーム選びと試合は一本道なので、下のタブを隠し、上に「← バトルへ」だけ置く。チーム選びの決定ボタンと、試合の結果は、画面の下に張りつく
- 幅は460px（広い画面では520px）の1列。スマホを片手で持って、親指で届く下側に主な操作を置く

## 3. 画面ごとのねらい
| 画面 | いちばん見せたいもの | 売り場の何で見せるか |
|---|---|---|
| 読む | スキャナ窓 | レジのスキャナのガラス面と赤いレーザー。窓そのものを押してもカメラが始まる |
| 値札 | キャラと値札（このアプリの顔） | 吊るし穴のある黄色い値札。強い味・弱い味、能力の役割、次の入荷まで値札の上で伝える |
| 棚 | 集まった姿 | 棚板の上に並び、下に値札（プライスカード）が下がる。値札の上の帯が味の色。入荷していれば赤い丸シール |
| バトル | 今日の挑戦者 | チラシ（赤い帯の見出し、「◯/◯限り」の丸い札）。届いた挑戦状は、縦書きの果たし状 |
| チーム選び | えらぶ手元 | 棚と同じ並び。えらぶとマスが黄色になり、順番の丸い札が貼られる |
| 試合 | 2チームと、自分の手元 | 相手は上、自分は下。相手は体ごとタップしてねらう（赤い値下げシール「ねらう」と足もとの赤い輪）。効き目はその味の色の小さな札。操作（ふく・技）は親指の届く下側。ふくは効き目が付くと白く押せるようになる。技のボタンはゲージが左からたまり、満タンで赤くなる。結果はレジのレシート（ちぎったギザギザの紙、点線リーダー） |

## 4. 部品（`src/styles/base.css`）
| 部品 | 元にした物 | クラス |
|---|---|---|
| ボタン | レジのキー | `.btn` `.btn.primary`（いちばん大事な1つだけ黒）`.btn.small` |
| 棚 | 棚板と値札（プライスカード） | `.shelf-list` `.thumb` `.shelf-tag` |
| 味 | 売り場の色分け（色の四角＋文字） | `.taste`（`tasteChip()` で作る） |
| 入荷の印 | 値引きシール | `.seal` |
| 結果の印 | はんこ | `.stamp` |
| お知らせ | 特売POPの帯 | `.notice` |
| 数字のラベル | 感熱ラベル | `.chip`（試し番号、ロット番号） |
| 相手チーム | 棚板に並ぶ商品 | `.foe-stage` |
| 味の輪 | レシート下の注意書き（1行の並び） | `.chain`（`tasteChainHtml()`） |

新しい部品が要るときは、先に「売り場の何に当たるか」を決めてから形にする。当たる物が思いつかないなら、文字だけで足りないかを先に考える。

## 5. 言葉づかい
- ボタンは、押すと何が起きるかをそのまま書く（「カメラで読む」「チームを組んで挑む」）
- 世界の言葉に寄せる：生む、棚、入荷、ロット、飲み干された、残り◯ml
- エラーは、何が起きたかと次にできることを1文ずつ。謝らない
- 説明文は足さない。見れば分かることは書かない（ルールの説明は「味の輪」の1行と、値札の上だけ）
