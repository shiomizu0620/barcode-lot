# 企画メモ（要約）

全文は claude.ai のプロジェクト「バーコードバトル」の `claude/企画メモ.md`。ここには実装で迷わないための要点と、見た目の方向だけ置く。

## 一点
読んだバーコードの縞がそのままキャラの体になる変身。

## 決まっていること
- 品番（JAN）で姿・名前・味・技が決まり、全国共通で変わらない
- ロットは消費サイクルが過ぎると新しく出る（バーコードだけで「買い直したっぽさ」を作る）
- 用語は品番・ロット・限定パッケージ。ポケモンの用語（種族値・個体値・色違い）は使わない
- 名前に「バーコードバトル」「バトラー」「〜モン」「Brawl」を使わない
- 画像生成AIは使わない。本番の絵は人が描いたパーツ＋縞
- 収益はB2B（メーカーコラボ、店頭QR、ご当地、受託）。一般向けは無料Web版

## 見た目の方向
舞台はスーパーの売り場。値札、レジのスキャナ、感熱紙のレシート、特売POP。

| 名前 | 色 | 使いどころ |
|---|---|---|
| 感熱紙 | #F3F5F2 | 背景（少し青みの白。クリーム色にしない） |
| インク | #1D1D22 | 文字、輪郭線、バーコード |
| 値札の黄 | #FFD83D | キャラの値札 |
| 特売の赤 | #E63B2E | レーザー、新ロットの札、フォーカス枠 |
| レシートの灰 | #B6BCC0 | 区切り線 |

- 文字：見出しとキャラ名は Dela Gothic One（POPの太さ）。本文は Zen Kaku Gothic New。数字（JAN）だけ等幅
- 形：キャラも部品も「太い黒の輪郭線」で統一（シール・ステッカーの手触り）。ボタンはレジのキーのように下辺が厚い
- 動き：大きく動くのは変身の一回だけ。それ以外は押したときの反応のみ
- キャラは値札の上に立つ。値札には吊るし穴、能力はレシートの点線リーダーで並べる
- 似せないもの：モンスター図鑑RPGのUI、ガチャのレア度演出、Material/Tailwindの初期見た目
